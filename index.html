✨ 为什么必须部署到网上？

当这个 HTML 保存到你自己电脑时，路径是 C:\Users\...。把它上传到免费托管服务器后，会生成一个专属公共网址，所有人访问同一个网址就能通过内置云端实时同步！

推荐方式 1：GitHub Pages (完全免费/最流行)

  1. 注册/登录 GitHub.com。
  2. 新建一个仓库 (Repository)，名字设为 mantou-harem。
  3. 将本网页重命名为 index.html 并上传到仓库主分支。
  4. 进入仓库 Settings -> Pages，分支选择 main 保存。
  5. 等待 1 分钟即可得到可分享的链接！

推荐方式 2：Vercel / Netlify (一键拖拽部署)

  1. 登录 Vercel.com 或 Netlify.com。
  2. 把包含 `index.html` 的文件夹直接拖拽到 Upload 区域。
  3. 自动生成可访问的免费 `.vercel.app` 链接发给朋友！
